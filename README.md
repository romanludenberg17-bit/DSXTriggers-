# DSXTriggers

Автоматические адаптивные триггеры **DualSense** для **Fallout: New Vegas**.

Плагин для xNVSE определяет оружие в руках игрока и автоматически выбирает профиль правого курка и цвет световой панели DualSense. Связь с DSX выполняется по UDP через `127.0.0.1:6969`.

## Что делает

| Тип оружия | Профиль триггера | Световая панель |
|---|---|---|
| Убранное оружие | Обычный | Серый |
| Ближний бой | Мягкий курок | — |
| Пистолет / револьвер | Полуавтомат | Жёлтый |
| Охотничья винтовка | Тяжёлый ход | Оранжевый |
| Снайперка / сильная оптика | Адаптивный профиль по эвристике увеличения | Синий |
| Дробовик | Жёсткий упор | Красно-оранжевый |
| Автоматическое оружие | Вибрация, частота зависит от скорострельности | — |
| Энергооружие | Мягкий ход / лёгкая пульсация | Зелёный |
| Миниган / огнемёт | Тяжёлая вибрация | — |
| Гранатомёт | Тяжёлый одиночный выстрел | — |
| Гранаты / мины / метательное | Упругое сопротивление | — |

## Требования

- Fallout: New Vegas версии **1.4.0.525** — Steam или GOG
- **xNVSE (New Vegas Script Extender)**
- **DSX** с включённым приёмом UDP-команд
- порт DSX: **6969**
- контроллер **DualSense**

## Установка

1. установи xNVSE и запускай игру через `nvse_loader.exe` либо через менеджер модов с NVSE.
2. скопируй `DSXTriggers.dll` в:

   ```text
   Fallout New Vegas\Data\NVSE\Plugins\
   ```

3. если папки `Plugins` нет — создай её.
4. запусти DSX, подключи DualSense и включи приём UDP-команд от модов на порту `6969`.
5. запусти игру и достань оружие. профиль правого курка и цвет световой панели должны изменяться автоматически.

## Если не работает

### плагин не загружается

проверь `Fallout New Vegas\nvse.log`. в нём должно быть видно, что `DSXTriggers` загружен.

если появляется `incompatible`, проверь версию игры: требуется **1.4.0.525**.

### триггер не реагирует

проверь, что в DSX включён приём UDP и используется порт `6969`.

### Windows или антивирус блокирует DLL

открой свойства DLL и нажми **«Разблокировать»**, если Windows показывает такую опцию.

### оружие определяется неправильно

определение некоторых типов оружия основано на эвристиках. в частности, снайперка определяется по сильному увеличению прицела. если конкретная винтовка определяется неверно, укажи её — эвристику можно скорректировать.

## Ограничения

сейчас плагин не отслеживает отдельно:

- перезарядку;
- прицеливание;
- пустой магазин.

для этих состояний потребуется читать дополнительные данные из игры и отдельно тестировать поведение непосредственно в Fallout: New Vegas.

## Исходный код

`DSXTriggers.c` содержит исходник плагина. отдельный Python-скрипт для работы проекта больше не требуется.
